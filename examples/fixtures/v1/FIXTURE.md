# FIXTURE.md

Authored synthetic demonstration data. Fictional identifiers. Not derived from any person, company, account or dataset. Generated by `tools/make_fixture.py` seed `42`, version v1.

- File: `complaints_synthetic.csv` (4000 rows, 24 months from 2024-07-01)
- Schema: CFPB Consumer Complaint Database column names (see DATA_CARD.md)
- Identifiers: `SYN-CMP-000001` style, never real complaint IDs
- Companies: obviously fictional demo names such as `Demo Bank One`
- Narratives: assembled from generic phrase templates, no personal data
- Deliberate properties: about 5% empty narratives, about 3% exact and 3% near-duplicate narratives, and a volume increase for `Money transfer / Fraud or scam` from month 22
- Class balance is skewed on purpose so that imbalance handling can be demonstrated

Regenerate: `python tools/make_fixture.py --rows 4000 --seed 42`
